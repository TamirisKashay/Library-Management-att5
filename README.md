# Library Management System – Assignment 4

## Description
This project is part of Assignment 4 and demonstrates the use of advanced Java features within a Library Management System.

## Implemented Features
- Generic `CrudRepository<T, ID>` interface
- Refactored `BookRepository` and `AuthorRepository` using SOLID principles
- Lambda expressions for sorting collections
- Utility class for sorting logic
- Java Reflection API to inspect class metadata at runtime

## Technologies Used
- Java
- JDBC
- Git & GitHub

## Key Concepts Demonstrated
- Generics
- Lambda expressions
- Reflection
- Repository pattern
- SOLID principles

## How to Run
Run the `Main` class from the `controller` package.
